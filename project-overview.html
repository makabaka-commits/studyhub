🔄 一次完整的请求流程（以"点赞笔记"为例）
① 浏览器
POST /notes/1/like → ② JWT 拦截器
解析 Token → ③ InteractionController
接收请求 → ④ InteractionService
点赞逻辑 → ⑤ 写入数据库
note_like 表 → ⑥ RabbitMQ
发送通知消息 → ⑦ WebSocket
实时推送通知 → ⑧ 返回
Result.success()

消息异步处理，降低通知落库对主请求耗时的影响

⭐ 技术亮点（面试重点）
技术点 实现方式 解决什么问题
JWT 认证 jjwt 0.12.6 + HandlerInterceptor + ThreadLocal 无状态认证，不需要 Session，适合前后端分离
接口限流 自定义 @RateLimit 注解 + AOP + Redis ZSet 滑动窗口 防止恶意刷接口（如刷点赞、刷评论）
实时通知 WebSocket + STOMP 协议 + SimpMessagingTemplate 点赞/评论/收藏时实时推送给用户，不用轮询
消息队列 RabbitMQ + DirectExchange + 手动确认 异步处理通知和浏览历史，解耦主流程
延迟队列 RabbitMQ TTL + 死信交换机（DLX） 延迟 5 分钟聚合通知，避免频繁通知骚扰
Redis 缓存 StringRedisTemplate + Cache-Aside 模式 + ZSet 热门排行 减少数据库查询，热门笔记实时排行
AI 集成 RestClient + DeepSeek API + Prompt Engineering 自动生成笔记摘要、基于笔记内容智能问答
XSS 防护 Jackson 自定义反序列化器 + HTML 实体转义 防止跨站脚本攻击，全局自动过滤
权限控制 @RequireAdmin 注解 + AOP 切面 + 角色枚举 区分普通用户和管理员，保护管理接口
Docker 部署 多阶段构建 + docker-compose 编排 + 健康检查 一条命令启动 MySQL + Redis + 应用
